# Support

This collection is maintained as coursework and a public example, not as a supported product.

## Where to ask

| Need | Where |
| --- | --- |
| A notebook fails, a path is wrong, or the README disagrees with the code | [Bug report](https://github.com/Rishabh-bgp/NIELIT-MACHINE-LEARNING-PROJECTS/issues/new/choose) |
| You want to add a project | Open a new-project issue before the pull request |
| You want the contribution rules | [CONTRIBUTING.md](CONTRIBUTING.md) |
| You found a committed secret | [SECURITY.md](SECURITY.md), privately |
| You want permission beyond the MIT License | The license already grants use, copy, and modification. Attribution is the courteous form. |

## What is not offered

- Assignment completion or graded submissions.
- A guarantee that a saved accuracy will repeat on a newer scikit-learn.
- Deployment help, model hosting, or a clinical or credit decision.
- Recovery of files that were never uploaded. Fake news, credit-card fraud, Parkinson's, and calories burnt still need local data files. House price prediction needs a replacement for `load_boston` on current scikit-learn.

## Environment

State Python, operating system, and the project folder when you ask for help. The notebooks were checked as files in this repository. They are meant to run after `pip install -r requirements.txt` from the project directory's point of view.
