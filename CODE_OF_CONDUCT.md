# Code of Conduct

This repository is a public teaching collection. People who report a bug, propose a project, or review a notebook are expected to keep the discussion technical and respectful.

## Expected behaviour

- Comment on the notebook, the data, and the result. Do not comment on the person.
- Disagree with a metric, a split, or a model choice by explaining the objection.
- Give newcomers a concrete next step when a pull request is incomplete.
- Credit data sources and other people's notebooks when you adapt them.
- Assume that a missing file or a Colab path is a mistake, not an attempt to mislead.

## Behaviour that is not acceptable

- Insults, slurs, or harassment, including in issue comments and commit messages.
- Publishing someone else's private information.
- Submitting data you are not allowed to share.
- Presenting an educational score as a clinical, credit, or security decision system.
- Repeated unsolicited requests after a maintainer has closed the issue with a reason.

## Scope

This standard applies to issues, pull requests, review comments, and any discussion that refers to this repository. It does not govern unrelated personal accounts.

## Reporting

Report conduct concerns to the maintainer, Er. Rishabh Aryan, through a private channel on GitHub rather than a public issue. Include links to the comments and a short description of what happened.

The maintainer may warn, edit, or close a comment, and may block further interaction on this repository. A report made in good faith will not be answered with retaliation in this repository.
