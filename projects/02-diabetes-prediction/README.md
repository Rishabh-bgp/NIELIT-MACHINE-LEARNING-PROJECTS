# 02. Diabetes Prediction

Predicts diabetes from clinical measurements using a scaled support vector classifier. Features include glucose, BMI, age, and diabetes pedigree function.

| Item | Detail |
| --- | --- |
| Task | Binary classification |
| Domain | Healthcare |
| Model | Support Vector Classifier |
| Reported result | Test accuracy 77.3% |
| Notebook | `Project_2_Diabetes_Prediction.ipynb` |
| Data | Bundled |

Dataset is included in data/.

Results are the scores saved in the notebook outputs. Re-run the notebook after any split or preprocessing change before treating them as current.

```bash
# from the repository root
pip install -r requirements.txt
jupyter notebook projects/02-diabetes-prediction/Project_2_Diabetes_Prediction.ipynb
```
