# 10. Heart Disease Prediction

Predicts the presence of heart disease from age, chest pain type, resting blood pressure, cholesterol, and related clinical features.

| Item | Detail |
| --- | --- |
| Task | Binary classification |
| Domain | Healthcare |
| Model | Logistic Regression |
| Reported result | Test accuracy 82.0% |
| Notebook | `Project_10_Heart_Disease_Prediction.ipynb` |
| Data | Bundled |

Dataset is included in data/.

Results are the scores saved in the notebook outputs. Re-run the notebook after any split or preprocessing change before treating them as current.

```bash
# from the repository root
pip install -r requirements.txt
jupyter notebook projects/10-heart-disease-prediction/Project_10_Heart_Disease_Prediction.ipynb
```
