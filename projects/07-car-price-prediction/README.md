# 07. Car Price Prediction

Estimates used-car selling price from year, present price, kilometres driven, fuel type, seller type, and transmission. Linear regression and Lasso are compared.

| Item | Detail |
| --- | --- |
| Task | Regression |
| Domain | Automotive |
| Model | Linear Regression and Lasso |
| Reported result | Test R² about 0.84–0.87 |
| Notebook | `Project_7_Car_Price_Prediction.ipynb` |
| Data | Bundled |

Dataset is included in data/.

Results are the scores saved in the notebook outputs. Re-run the notebook after any split or preprocessing change before treating them as current.

```bash
# from the repository root
pip install -r requirements.txt
jupyter notebook projects/07-car-price-prediction/Project_7_Car_Price_Prediction.ipynb
```
