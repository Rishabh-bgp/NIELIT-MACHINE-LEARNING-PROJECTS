# 06. Wine Quality Prediction

Predicts red-wine quality from physicochemical measurements. A random forest is trained after exploratory correlation analysis.

| Item | Detail |
| --- | --- |
| Task | Classification |
| Domain | Food and chemistry |
| Model | Random Forest Classifier |
| Reported result | Accuracy 92.5% |
| Notebook | `Project_6_Wine_Quality_Prediction.ipynb` |
| Data | Bundled |

Dataset is included in data/.

Results are the scores saved in the notebook outputs. Re-run the notebook after any split or preprocessing change before treating them as current.

```bash
# from the repository root
pip install -r requirements.txt
jupyter notebook projects/06-wine-quality-prediction/Project_6_Wine_Quality_Prediction.ipynb
```
