# 13. Customer Segmentation with K-Means

Segments mall customers by annual income and spending score. The elbow method selects five clusters.

| Item | Detail |
| --- | --- |
| Task | Clustering |
| Domain | Retail analytics |
| Model | K-Means (k = 5) |
| Reported result | Elbow method, 5 clusters |
| Notebook | `Project_13_Customer_Segmentation_using_K_Means_Clustering.ipynb` |
| Data | Bundled |

Dataset is included in data/.

Results are the scores saved in the notebook outputs. Re-run the notebook after any split or preprocessing change before treating them as current.

```bash
# from the repository root
pip install -r requirements.txt
jupyter notebook projects/13-customer-segmentation/Project_13_Customer_Segmentation_using_K_Means_Clustering.ipynb
```
